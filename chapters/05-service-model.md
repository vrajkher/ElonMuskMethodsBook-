# પ્રકરણ 5: Service model

## Software નહીં, પરિણામ વેચો

CA firm તમને કામ મોકલે અને તૈયાર, તપાસી શકાય તેવું, sign થયેલું output નક્કી ભાવે પાછું મેળવે. તમે તેમની back office છો, અડધા ખર્ચે.

ઉદાહરણ: "GST reconciliation તૈયાર, GSTIN દીઠ, નક્કી ભાવ, 24 કલાકમાં."

## Service બનાવવાના પાંચ પગલાં

1. **એક કામ પસંદ કરો.** વધારે volume વાળું અને નિયમ આધારિત, જેમ કે GST 2B reconciliation અથવા TDS return.
2. **5–10 firms માટે હાથે કરો.** દરેક step નો સમય stopwatch થી માપો.
3. **પહેલા કાઢો, પછી automate કરો.** જે step કોઈને જોઈતા નથી તે દૂર કરો, પછી સૌથી વધુ સમય ખાતું step પહેલું automate કરો.
4. **Unit દીઠ ભાવ રાખો.** GSTIN દીઠ, return દીઠ, અથવા audit file દીઠ, બજાર ભાવથી અડધો.
5. **એક આંકડો માપો.** કામ દીઠ માણસની મિનિટ દર અઠવાડિયે ઘટવી જોઈએ. તે લગભગ 80% ઘટે ત્યારે બીજું કામ ઉમેરો.

## ત્રણ આંકડા જે રોજ જોવાના

| આંકડો | શું બતાવે |
|---|---|
| કામ દીઠ માણસની મિનિટ | ખર્ચ ઘટે છે કે નહીં |
| ભૂલનો દર | ગુણવત્તા જળવાય છે કે નહીં |
| Turnaround time | ઝડપ વધે છે કે નહીં |

## 50% ભાવનું ગણિત

50% ભાવે વેચવું અને નફો રાખવો હોય તો ખર્ચ 50% થી વધારે ઘટવો જોઈએ. ખર્ચનો મોટો ભાગ માણસના કલાકો છે, એટલે લક્ષ્ય હાથના કલાકોમાં લગભગ 80% ઘટાડો છે.
